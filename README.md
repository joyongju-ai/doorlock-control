# doorlock-control

STM32로 만든 비밀번호 입력식 도어락이다. 4x4 키패드로 비밀번호를 입력하고,
4자리 7-세그먼트로 입력 상태를 보여주며, 결과를 부저음으로 알린다.
기능을 키패드, 표시, 부저, 비밀번호 로직으로 나눠 모듈로 구성했다.

2인 팀으로 진행했으며, 소프트웨어 전반(키패드 입력, 세그먼트 표시,
비밀번호 검증, 부저 제어)을 담당했다.

## 개발 환경

- MCU: STM32H503 (HAL)
- IDE: STM32CubeIDE
- 언어: C
- 입력: 4x4 키패드
- 표시: 4자리 7-세그먼트 디스플레이
- 출력: 부저 (TIM3 PWM)

## 파일 구조

```
Inc/   keypad.h  display.h  buzzer.h  doorlock.h
Src/   keypad.c  display.c  buzzer.c  doorlock.c  main.c
```

하드웨어를 직접 다루는 코드(keypad, display, buzzer)와 비밀번호 판단
로직(doorlock)을 나눴다. doorlock은 입력값을 관리하고, 표시할 숫자를
display에 넘겨주는 식으로 역할을 분리했다. 핀 번호나 세그먼트 패턴 같은
하드웨어 세부사항은 각 모듈 안에만 두었다.

## 동작

`*` 또는 `#`를 누르면 입력 모드로 들어가고, 숫자 4자리를 입력하면
저장된 비밀번호와 비교한다. 일치하면 성공음(짧게 3번), 틀리면 실패음
(길게 1번)을 낸다. 입력 도중 3초 동안 키가 없으면 자동으로 초기화된다.

## 구현

### 세그먼트 멀티플렉싱

7-세그먼트 4자리를 동시에 켜면 핀이 부족하다. 그래서 한 번에 한 자리만
켜고 빠르게 돌아가며 표시하는 멀티플렉싱 방식을 썼다. TIM3 주기 인터럽트
에서 `Display_Refresh()`를 호출해 매번 다음 자리로 넘기고, 잔상 효과로
4자리가 동시에 켜진 것처럼 보이게 했다.

화면 갱신을 인터럽트에 맡긴 덕분에, 메인 루프에서는 키 입력과 비밀번호
판단만 처리하면 됐다.

### 입력 타임아웃

입력을 하다 멈췄을 때 이전 입력이 계속 남아 있으면 안 된다고 판단했다.
그래서 마지막 입력 시각을 기록해두고, `HAL_GetTick()`으로 현재 시각과
비교해 3초가 지나면 입력을 초기화한다. `HAL_Delay`로 멈춰서 기다리지
않고 시간 비교로만 처리해, 타임아웃을 기다리는 동안에도 다른 동작이
막히지 않는다.

## 아쉬운 점

부저 알림음은 `HAL_Delay`로 소리 길이를 만들었다. 그래서 알림음이
울리는 짧은 시간 동안에는 키 입력을 받지 못한다. 타임아웃 판정은
논블로킹으로 처리했지만, 알림음까지 완전히 논블로킹으로 만들려면 음
출력도 타이머 기반으로 다시 설계해야 한다.

비밀번호도 코드에 고정되어 있어, 사용자가 직접 변경하는 기능은 없다.
